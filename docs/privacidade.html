Política de Privacidade

Candeia Bíblica · Última atualização: 18 de setembro de 2026

O que é este aplicativo

O aplicativo Candeia Bíblica é uma ferramenta de uso pessoal do responsável pelo canal Candeia Bíblica. Ele serve para uma única coisa: publicar os vídeos do próprio canal no YouTube e no TikTok. Não é oferecido ao público e não tem outros usuários.

Quais dados o aplicativo acessa

  • YouTube: apenas a permissão de enviar vídeos (youtube.upload) para o canal da conta que autorizou o acesso.
  • TikTok: a permissão de enviar vídeos para a conta que autorizou o acesso e o nome de exibição dessa conta, usado só para confirmar que a conta certa foi conectada.

O aplicativo não lê vídeos, comentários, mensagens, inscritos, seguidores nem qualquer dado de espectadores. Não coleta, não vende e não compartilha dados pessoais de ninguém.

Como as autorizações são guardadas

Os códigos de acesso gerados na autorização ficam guardados apenas no computador do responsável pelo canal e nos segredos criptografados do repositório do projeto no GitHub, de onde a publicação automática é feita. Eles são usados exclusivamente para publicar os vídeos do canal.

Dados das APIs do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar o acesso

  • Google e YouTube: em myaccount.google.com/permissions.
  • TikTok: no aplicativo, em Configurações e privacidade, na parte de aplicativos conectados.

Contato
